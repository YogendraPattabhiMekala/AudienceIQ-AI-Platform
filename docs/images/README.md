# Screenshots Guide

Place the captured application screenshots in this directory when publishing:

1. `01-overview-dashboard.png` — Overview metrics, data freshness indicators, and LTV by channel.
2. `02-customer-explorer.png` — Filtered customer table (e.g., churn > 0.70 & LTV > $1,000) with column selection.
3. `03-dynamic-segment-builder.png` — High Value Churn Risk segment details with structured AND/OR rules and simulated activations.
4. `04-ask-audienceiq.png` — Governed AI natural-language query with expanded "How this was calculated" transparency drawer.
5. `05-data-operations.png` — Pipeline run history, sync freshness matrix, and warehouse-to-product sync architecture.

Recommended resolution: 1280x800 or 1920x1080 (PNG format).
